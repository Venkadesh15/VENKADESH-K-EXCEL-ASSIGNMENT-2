# 📊 Excel Data Cleaning and Transformation

## 📌 Project Overview

This project demonstrates **Data Cleaning and Transformation using Microsoft Excel**. The objective was to clean raw data, correct inconsistencies, handle missing values, remove duplicates, transform columns, and prepare the dataset for further analysis.

## 🧹 Data Cleaning and Transformation

### 1. Handling Missing Values

**Price ($)**

* Identified missing values in the Price column.
* Used `IF`, `ISBLANK`, and `ROUND` functions to handle missing values.
* Formatted the Price column using the appropriate number format.

**Category**

* Identified missing values in the Category column.
* Used `IF` and `ISBLANK` to handle blank values.
* Analyzed category values and imputed the required missing values.

### 2. Correcting Inconsistent Data

Identified and corrected inconsistent text and spelling errors in the **Product Name** and **Category** columns.

**Corrections performed:**

* `laptop` → `Laptop`
* `smartphone` → `Smartphone`
* `headphones` → `Headphones`
* `Electroni` → `Electronics`

Used **Find and Replace** to standardize the values.

### 3. Removing Duplicates

* Identified duplicate records in the dataset.
* Used the **Remove Duplicates** feature to eliminate unnecessary duplicate rows.

### 4. Splitting and Merging Data

**Splitting Product ID**

* Extracted information from the Product ID into separate columns, including:

  * Manufacturing Date
  * Manufacturing Month
  * Country Code

**Merging Columns**

* Combined **Product Name** and **Brand** to create a new **Product Brand** column.

### 5. Number and Date Formatting

**Price**

* Converted the Price column to **Currency format**.

**Manufacturing Date**

* Formatted the Manufacturing Date as `DD-MM-YYYY`.

### 6. Conditional Formatting

**Price**

* Applied a **Color Scale** to visually represent different price ranges.

**Category**

* Created a custom conditional formatting rule to highlight the **Electronics** category.
